## 如何复验

先按照[快速开始](getting-started.md)完成一次构建以下载依赖，然后在 `esp32` 目录运行：

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
```

主机需要 Python、C/C++ 编译器和测试依赖。密码学测试需要主机 Mbed TLS / pkg-config，以及已激活的 ESP-IDF 环境，安装方法见[上游测试说明](../../esp32/README.md#tests)。检查最终统计是否含 `skipped=`，不要把有跳过的运行写为全部覆盖。

当前翻译测试会编译真实翻译模块，但它不验证实体屏幕、触摸、语言的 Flash 持久化或云端可达性。这些项目仍需上板分别验证。

UI 变更还应编译至少一个其他共用 UI 的板型，并记录板型、源码版本、工具链版本与测试日期。只有实际运行了的设备才标记为实机通过。
